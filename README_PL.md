# Anchor Arsenal — NeoForge 1.21.1

Projekt źródłowy moda Anchor Arsenal. Wymaga Java 21. Projekt jest przygotowany do budowania przez Gradle 8.10.2 i NeoForge 21.1.172.

## Budowanie na GitHub Actions
1. Utwórz repozytorium GitHub i wgraj całą zawartość tego folderu na gałąź `main`.
2. Otwórz zakładkę **Actions**.
3. Wybierz **Build Anchor Arsenal** i kliknij **Run workflow**.
4. Po zakończeniu otwórz wykonane zadanie i pobierz artefakt `Anchor-Arsenal-1.0.0`.
5. W ZIP-ie artefaktu znajdziesz JAR. Włóż go do folderu `mods` profilu NeoForge 1.21.1.

## Ważne ograniczenia tej wersji
To pierwsza wersja implementacyjna: rejestruje 21 broni i ich podstawowe statystyki. Nie ma jeszcze finalnych modeli/tekstur, receptur, animacji, efektów obszarowych, mnożnika XP szabli, podwójnego combo sztyletów, zasięgu 5 bloków działającego w mechanice trafienia ani podwójnego ataku z wyskoku maczugą. Te funkcje wymagają dalszej implementacji i testów. Nie oznaczaj tej wersji jako pełnej zgodnej z całą specyfikacją.
